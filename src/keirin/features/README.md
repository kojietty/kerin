# 特徴量カタログ & オッズ乖離の考え方

## なぜ「オッズ乖離」が重要か

競輪の三連単はパリミュチュエル方式（みんなの賭け金を分け合う）。
つまり**オッズ = 世間の平均的な予想の裏返し**です。

> 「選手の実際の強さ」と「オッズが暗示している強さ」が大きくズレている組み合わせを買う = EV > 1.0

世間がある選手を過小評価するパターンを以下に整理します。

---

## 世間が間違えやすい5つのパターン

### 1. 得点オッズ乖離（`score_odds_gap`）
**何**: 競走得点では場内2番手なのに、オッズでは4番人気扱い。  
**なぜ起きる**: 知名度・前走の見た目・脚質（逃げ選手が目立つ）などで人気が歪む。  
**使い方**: `odds_rank - score_rank` が大きいほど「実力の割に買われていない」。

### 2. 休養明け割引（`rest_day_signal`）
**何**: 前走から15日以上空いているとオッズが高くなりやすい。  
**なぜ起きる**: 「間が空いた = 調子が落ちている」と人々が思い込む（リサーチによると実際はそうでもない）。  
**使い方**: 休養日数が長くても上位級班 × 過去成績が安定している選手に注目。

### 3. バンク適性未認知（`venue_specialist_score`）
**何**: 小倉では3着内率70%なのに小倉でのオッズは6番人気。  
**なぜ起きる**: 一般のファンは全選手のバンク別成績を調べない。  
**使い方**: `venue_top3_rate - overall_top3_rate` が大きい選手 = 局所スペシャリスト。

### 4. 前走着外れ × 地力高（`form_rebound_signal`）
**何**: 前走5着だが、直近20走平均は2.5着。  
**なぜ起きる**: 人は直前の結果に引きずられる（ギャンブラーの誤謬）。  
**使い方**: 前走が悪くても長期成績が安定している選手は「見かけ倒しの人気薄」になりやすい。

### 5. 実力番手（`line_mismatch_signal`）
**何**: 得点10点高い選手が弱い先行の後ろ（番手）に付いている。  
**なぜ起きる**: 「番手 = 先行を追いかけるだけ」とファンが思い込む。実際は先行が弱ければ番手選手が外に出てごぼう抜きすることが多い。  
**使い方**: `is_follower AND rating_vs_leader_gap ≥ 3点` = 実力番手シグナル。

## 全特徴量リスト

### 選手実力系

| 特徴量 | 説明 |
|---|---|
| `rating` | 競走得点（公式ランキング指標。高いほど強い） |
| `rank_s1 / s2 / a1 / a2 / a3` | 級班ワンホット（S1 > S2 > A1 > A2 > A3） |

### 直近成績系

| 特徴量 | 説明 |
|---|---|
| `avg_finish_5` | 近5走平均着順（低いほど良い） |
| `top3_rate_5/10/20` | 近5/10/20走での3着内率 |
| `win_rate_10` | 近10走の優勝率 |
| `form_trend` | 近5走3着内率 - 近20走3着内率（正 = 上昇傾向） |
| `rest_days` | 前走からの日数（上限90日）|

### 決まり手系

| 特徴量 | 説明 |
|---|---|
| `km_nige` | 逃げで勝った割合 |
| `km_maki` | 捲りで勝った割合 |
| `km_sashi` | 差しで勝った割合 |
| `km_mark` | マーク（番手捲り等）で勝った割合 |

### バンク・会場系

| 特徴量 | 説明 |
|---|---|
| `bank_length` | 当日バンク周長（333/400/500m） |
| `venue_top3_rate` | 当該バンクでの3着内率（直近2年） |
| `venue_n_races` | 当該バンクでのサンプル数 |
| `venue_specialist_score` | バンク3着内率 - 全体3着内率（正 = バンク適性あり） |
| `top3_333/400/500` | バンク長別の3着内率 |

### ライン系

| 特徴量 | 説明 |
|---|---|
| `line_pos` | ライン内の位置（1=先頭, 2=番手, 3=三番手） |
| `line_len` | ラインの人数（長いほど有利） |
| `is_leader` | 先頭（先行選手）か（1/0） |
| `is_follower` | 番手以降か（1/0） |
| `is_solo` | 単独（ライン未形成）か（1/0） |
| `rating_vs_leader_gap` | 自分の得点 - 先頭選手の得点（正 = 実力番手） |

### ギア比系

| 特徴量 | 説明 |
|---|---|
| `gear_ratio` | ギア比（生値） |
| `gear_z` | レース内でのz-スコア（0 = 平均的） |
| `gear_rank` | レース内でのギア比順位（1 = 最高ギア） |
| `gear_above_field` | 場内平均より高いか（1/0） |

### レース文脈系

| 特徴量 | 説明 |
|---|---|
| `grade_gp/g1/g2/g3/f1/f2` | グレードワンホット |
| `car_no` | 車番（コース取り影響のためそのまま保持） |

### オッズ乖離シグナル（推論時のみ付加）

| 特徴量 | 説明 |
|---|---|
| `score_odds_gap` | オッズ順位 - 得点順位（正 = 実力より人気薄） |
| `rest_day_signal` | 休養日数から算出（0〜3） |
| `venue_specialist_discount` | バンクスペシャリストか（0/1） |
| `form_rebound_signal` | 前走着外れ × 地力高（0/1） |
| `line_mismatch_signal` | 実力番手シグナル（0/1） |
| `divergence_score` | 上記の重み付き合計（高いほど割安感あり） |

---

## ターゲット変数

| 列名 | 定義 |
|---|---|
| `label_top3` | 当該選手が3着以内に入ったか（1=入った, 0=入らなかった） |

1レース × 1選手 = 1行のフォーマット（7〜9行/レース）。LightGBMの二値分類タスクに直接投入。

---

## データ収集の優先順位

1. **必須（P1完了時点で収集可能）**: entries, results, races, venues → player_race_log を `sync_player_race_log()` で自動生成。
2. **重要（P2で追加）**: 選手プロフィールページから取得できる月別成績・バンク別成績の詳細。
3. **あれば更に良い（P5）**: 対戦成績（特定の選手Aが選手Bと同じレースに出た際の着差）、調整前ギア比変化。
